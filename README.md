# Killed by OpenAI

An independent community archive documenting products, models, APIs, services, and features retired by OpenAI.

Killed by OpenAI preserves a simple public record of what existed, when it launched, when it ended or is scheduled to end, and the source used for that retirement record. It is not affiliated with or endorsed by OpenAI.

## Contributing

Corrections and new entries are welcome. Open an issue using the repository templates or submit a pull request that updates `graveyard.json` with a source link.

## Development

```bash
yarn
yarn lint
yarn test
yarn build
```
